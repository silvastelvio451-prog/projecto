# Vida Leve Angola

Projecto de site educativo sobre bem-estar, alimentação equilibrada e movimento acessível, pensado para o público angolano.

## Criar o site com Lovable
1. Abre https://lovable.dev/ e inicia sessão.
2. Liga a tua conta GitHub ao Lovable, se ainda não estiver ligada.
3. Escolhe o repositório `silvastelvio451-prog/projecto`.
4. Copia o conteúdo de [lovable-prompt.md](./lovable-prompt.md) e cola-o no Lovable.
5. Revê o site gerado antes de publicar.

## Nota de saúde
O site deve promover hábitos sustentáveis e informação educativa. Não deve prometer resultados rápidos nem substituir aconselhamento de profissionais de saúde.
